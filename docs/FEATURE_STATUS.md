## Recent Verified Increment

The API reads `LAB_DETECTION_THRESHOLD` (3–65536; default 8) and `LAB_DETECTION_SOURCE_ALLOWLIST` (comma-separated IPv4/IPv6 addresses or CIDRs) at startup. Invalid values stop startup with an explicit error. Matching source events continue to be ingested and queryable but are omitted from scan alert generation. Unit and API tests cover the behavior.

API authentication and backend RBAC now protect all data routes except health and sign-in; writes require CSRF validation. Audit entries use the authenticated username. Uploads require a bounded content length, are limited to 5 MiB and 20,000 lines, return at most 100 parse errors, and are limited to 10 requests/minute per client in this single-process deployment. Detection context queries are capped. The limiter is in-memory and must be replaced with a shared store before multiple workers.

PDF reports use persisted network events, alerts, incidents, and audit notes, with selectable periods and a severity chart. Report tests verify a generated PDF's parseability, report text, metric counts, and preview headers. The dashboard provides a weekly PDF link. Offline PCAP upload is bounded, authenticated, and covered by IPv4/IPv6 parser tests plus API persistence/deduplication tests. Optional Splunk/Elasticsearch delivery uses real HTTP clients but has only mocked contract coverage; external service ingestion/search is unverified. An initial Alembic migration is tested on SQLite and PostgreSQL 17; a FastAPI database health request also passed against PostgreSQL. Local Playwright verifies sign-in, analyst provisioning, synthetic event persistence/detection, alert investigation, incident assignment/status, audit actor, and PDF download. Compose images built and the stack passed health, migration, database, authenticated proxy, and CSRF smoke checks. Python dependency audit found no known vulnerabilities in the current pinned set; the full npm tree still reports moderate development-only `minimatch` advisories, with no high/critical findings. No remote GitHub Actions run has been observed.
